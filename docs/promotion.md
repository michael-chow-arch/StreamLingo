## Short social post — English

Live streams. AI-translated.

Already running Ollama? Put it to work on your next YouTube livestream. StreamLingo captures the tab's audio directly and generates AI-translated captions inside the player. It does not depend on the streamer providing captions, and the original audio keeps playing.

English → Chinese, Chinese → English, or automatic source detection with Chinese or English output. Local speech recognition. Your own Ollama model. Open source under MIT.

Setup once. Start daily. The Windows preview includes the built extension—no Node.js, and no terminal commands to start it each day.

Try the preview and tell us what you watched: [StreamLingo on GitHub](https://github.com/michael-chow-arch/StreamLingo).

The Windows preview requires an NVIDIA GPU, CUDA 12 cuBLAS, complete cuDNN 9 for CUDA 12, and 64-bit Python 3.11–3.13. A separate local speech service and initial dependency/model downloads are required. Speed and accuracy depend on your hardware, models, and audio; subtitle reading time can add delay. Not yet in the Chrome Web Store.

## Release introduction draft / 发布简介草稿

**v0.2.0 Windows preview — reusable introduction**

StreamLingo turns YouTube livestream audio into AI-translated captions without depending on captions from the streamer. Reuse your existing Ollama model, choose Chinese or English output, and follow the conversation inside the player. The Windows preview includes the built extension: run Setup once, then double-click Start for daily use. No Node.js required. Setup still needs a local Python service and initial dependency/model downloads; load the extension manually in Chrome. Performance depends on your machine and models.

**v0.2.0 Windows 预览版——可复用简介**

StreamLingo 直接从 YouTube 直播音频生成 AI 翻译字幕，无需主播提供字幕。复用已有 Ollama 模型，选择中文或英文输出，在播放器内跟上直播内容。Windows 预构建包自带扩展，首次运行 Setup，日常双击 Start，无需 Node.js。首次仍需准备本地 Python 服务并下载依赖和语音模型，扩展需在 Chrome 手动加载；运行效果取决于机器和模型。

## Reuse notes / 使用说明

Pair promotional copy with the original demonstration assets in [assets](assets/). Identify simulated interface content as a demonstration. Do not describe demo subtitles as evidence of live recognition accuracy, or reuse a third-party stream's face, account, contact information, or footage without permission.

Keep the local-service requirement visible when using a short excerpt. Do not imply a standalone, zero-setup extension, zero latency, perfect automatic language switching, a free hosted AI service, or an existing store listing. Default processing is local; a user-configured remote Ollama endpoint receives recognized text and context. See [getting started](getting-started.md) and the [privacy policy](privacy-policy.md).

配图请使用 [assets](assets/) 中的原创演示素材，并注明模拟内容。演示字幕不是实时识别准确性的证明；未经授权，不使用第三方直播的人像、账号、联系方式或画面进行宣传。

摘用短文案时请保留本地服务要求。不承诺“仅装扩展即可用”“零配置”“零延迟”“混合语言完美识别”“免费云端 AI”或“已经上架”。默认处理在本机；用户改用远程 Ollama 时，识别文本与上下文会发送至该地址。详见[安装指南](getting-started.md)与[隐私说明](privacy-policy.md)。
