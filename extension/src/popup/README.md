# 控制界面模块

文件划分为 `index.ts`、`popup.css` 与 `extension/popup.html`，使用原生 HTML、CSS 和 TypeScript。构建输出平铺的 `popup.html`、`popup.css` 和 `popup.js`。

提供开始、停止、状态、错误提示以及服务地址、字号、英文显示开关。通过 background 查询状态和保存设置。启动基于用户明确点击，目标为点击时的 YouTube 标签页。

弹窗本身不持有音频或 WebSocket；关闭弹窗不影响正在运行的会话。首版设置与控制放在同一个弹窗，暂不增加独立 options 页面。

服务地址首版只允许本机 `http://127.0.0.1:<port>` 或 `http://localhost:<port>` 根地址。会话运行时禁用修改设置，防止前台输入与实际采集配置不一致。连接测试显示后端模式：demo 明示固定示例、mock 明示测试中文、disabled 明示仅英文。后端连接信息显示当前扩展 Origin，便于填写允许列表。

识别/翻译说明完全由 `/health` 返回的模式驱动。configured 表示后端已配置真实翻译接口；文案不会把接口预留状态写死，也不会把配置完成当作某一句译文已成功生成。尚未取得健康信息时展示待连接说明。
右上角使用原生语言选择框（中文/English），支持键盘操作与可见焦点。切换即时更新 `html.lang`、静态标签、状态、错误及提示；不重建表单、不覆盖未保存的输入、不关闭已展开设置，也不启停采音。语言偏好独立保存，其他设置仍通过“保存设置”提交。
