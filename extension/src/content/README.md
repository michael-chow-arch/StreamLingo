# 页面字幕模块

已实现文件：

- `index.ts`：注册消息、页面变化和清理入口，避免重复注入；定位播放器，观察替换、全屏和视频切换。
- `subtitle-view.ts`：创建隔离样式的字幕容器，以纯文本更新中英字幕。
- `subtitle-store.ts`：按 session ID、segment ID、revision 合并字幕并限制保留条数。
- `subtitle-presentation.ts`：把片段状态转为明确的展示标签，并保留识别/翻译文本。

播放器挂载变化只重建视图；视频标识改变或页面离开时请求结束当前会话，清除字幕并等待用户重新开始。时间戳基于采集音频的会话时钟，不使用直播视频的 currentTime 直接对齐。

中文迟到时只更新对应字幕，不能覆盖较新的字幕或把旧句重新顶到当前行。测试译文需显示测试标记。停止会话时立即清空，忽略迟到结果。

视图最多显示两个分组：最近返回的“已译片段”（含其自己的英文）和最新的“当前英语”。当前句完成翻译后合并为一个双语分组；若较早译文乱序返回，仍获得独立阅读位置，不替换当前句的对应关系。测试中文明确标注“测试译文”。

缓存最多 8 个片段，已被淘汰的片段不会被迟到结果重新加入。每个分组从有意义的文本/翻译状态变化开始保留 12 秒，独立到期；仅 revision 递增而文本未变不会延长显示。迟到中文从返回时计时，当前英文仍按自己的更新时间到期。停止或导航时清理所有定时器、DOM 与缓存，旧会话无法重新显示。

pending / error / skipped 分别提示“翻译中”“翻译暂不可用”“本句翻译已跳过”；没有中文时始终保留英文，即使关闭了英文原文显示。字幕数据只通过 textContent 写入。两个分组用边界和标签区分，中文最多两行、对应英文一行；小播放器压缩为各一行，未译的当前英文在普通播放器最多两行。状态提示使用单个无焦点移动的 live region，避免每次临时识别更新都触发多处播报。
界面语言监听独立的 `uiLanguage` 存储键。切换只更新字幕组标签、状态和无障碍名称，英文原文与中文译文保持原样；不会重建会话、清空字幕或重置 12 秒的显示期限。
